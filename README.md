# ΔETHERFRAGM

Navigateur privé minimaliste — *Surfe sans laisser de trace*.

## Fonctionnalités

- Bouclier anti-pistage EasyPrivacy (~25 000 domaines)
- Forçage HTTPS + purgeur de liens (utm, fbclid, gclid…)
- Méta-moteur de recherche (web / images / vidéos / actualités) avec pagination
- Coffre-fort de mots de passe chiffré AES-256-GCM (clé dérivée scrypt)
- Canaux fantômes éphémères (sessions isolées, autodestruction à la fermeture)
- Mode lecture phosphore + traduction automatique
- Souvenirs CRT (captures signées)
- Radar à traqueurs animé + palette de commandes (Ctrl+K)
- Gestionnaire de téléchargements avec barre d'état permanente
- Bulletin de santé interne (`aether://diag`)
- Raccourcis clavier complets (Ctrl+T/W/L/K/F, F11, Ctrl+Shift+X)
